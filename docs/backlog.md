## 功能拓展候选

按"减少手机端操作"的价值排序，尚未开始实现。

| 项目 | 价值 | 可行性 |
|---|---|---|
| 审批记忆 | 同一回合内针对完全相同的审批请求（同工具、同参数）记住上一次决定，减少反复点击 | 桥接侧可实现；DSH 的审批粒度只有 `allowed-once` 与 `rejected`，因此这属于替用户做安全决定，须显式开启且范围受限 |
| 长回答自动转文件 | 超过 N 条时改为「首段 + 完整文件」，减少消息刷屏 | 桥接侧可实现，成本小 |
| 会话搜索（`/find`） | 在手机端找回"当时讨论某事的那个会话"，并可直接 `/resume` 过去 | DSH 的 `sessionController.search` 已提供带摘要的搜索结果，桥接只需暴露 |
| 截图窗口菜单 | `/screen` 列出可截取的窗口编号，`/screen <编号>` 直接截取，免去输入进程名 | 需扩展 `tools/capture-window.ps1` 增加列举模式 |
| 待办提醒可见 | `/status` 中显示当前会话的待办提醒（读取会话中的 `schedule/change` 事件） | DSH 的 schedule 未对外提供服务，仅有 agent 工具，因此只能读取、不能由命令创建 |
